# QCurl 2.0.0 release notes

Status: current development candidate. The `v2.0.0` tag and remote release do not exist.

## Highlights

- Moves the current release identity to `PROJECT_VERSION=2.0.0` and shared-library `SOVERSION=2`.
- Defines the Core contract as source-compatible within 2.x while requiring downstream rebuilds for every QCurl update; 2.0 does not promise binary compatibility or establish a v2 ABI baseline.
- Removes the lossy `QMap<QByteArray, QByteArray>` cache-policy overloads in favor of ordered raw response headers.
- Adds direct synchronous reentry coverage for all four `QCWebSocketPool` public signals and its `acquire`, `release`, and `clearPool` paths.
- Adds local keepalive evidence for matching, delayed, wrong, absent, and disconnecting Pong behavior.
- Binds release manifests to immutable release authority instead of mutable task progress or historical review output.
- Uses six explicit producer trees for release, test, and sanitizer evidence; shared and static package evidence is generated from `BUILD_TESTING=OFF` trees by installed-package consumers.
- Keeps four logical consumer surfaces while reducing the physical package to three libraries: Blocking Extras remains an explicit `QCurl::BlockingExtras` interface target, with its implementation and symbols embedded in Core.
- Rejects `QCURL_BUILD_SHARED_LIBS=OFF` with `BUILD_TESTING=ON` during configure using the fixed diagnostic `QCURL_STATIC_TESTING_UNSUPPORTED：静态构建不支持测试`.
- Changes `QCWebSocketPool::release()`, `clearPool()`, and `setConfig()` to `[[nodiscard]] bool` APIs with an optional `QString *error` output; failed synchronous calls do not mutate pool state.

## Lane scheduler 精简

- manager 承接调度通知、同步启动前取消及 Pending 的 defer/undefer/优先级控制；命令返回
  `SchedulerCommandResult`，拒绝无副作用，借用 reply 与值快照的生命周期有明确区分。
- scheduler 私有化；旧公开实现类型、Config/Statistics/LaneConfig、quantum、可配置
  default lane、UnknownLaneMode 及旧带宽开关退出。下游改用 manager 和单一启动权重。
- 原队列归并为唯一非 QObject admission core，修复 busy lane 删除、policy 重入、
  重复取消计数及极端权重算术；保留 start ticket、Qt 生命周期和既有 multi。
- `admissionByteBudget` 仅延迟新 admission，按需单次唤醒；不提供 manager 聚合速率整形。
- 这是当前开发候选的有界 API/ABI hard-break，不保留兼容壳；详见
  [lane scheduler 用户合同](../user/lane-scheduler.md)。

## Compatibility

This is an intentional hard-break from the published v1 API and ABI. Downstream users must migrate the removed cache-policy overloads and rebuild against the v2 headers and libraries. After adopting 2.0, the documented Core surface is the 2.x source compatibility boundary, but every QCurl update still requires rebuilding and relinking downstream binaries. `SOVERSION 2` is a loader namespace, not a binary compatibility promise. No alias, wrapper, shim, or compatibility switch is provided.

## Evidence boundary

The release-candidate state is local and reproducible. It is not a tag, remote push, GitHub Release, or downloadable asset.
